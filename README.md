# 정회광 | AI로 아이디어를 실행하는 창업가

연세대학교 화학과

필요한 지식과 기회를 직접 찾아 배우고, 사람을 연결하고, 해결책을 실행합니다. 제품 개발뿐 아니라 고객 검증, 사업 모델, 파트너십, 행사 운영까지 직접 부딪치며 경험을 쌓고 있습니다.

[TripPups](https://trip-pups.com) · [해커온](https://hackon.kr)

## 주요 프로젝트

### Mail Notifier — 처음 만든 프로젝트

대회와 면접 결과를 기다리며 하루에도 여러 번 메일함을 확인했습니다. 발표 시각이 정해져 있지 않아, 기다리던 메일이 오면 휴대폰으로 알려주는 도구를 만들었습니다.

**Gmail → Gemini로 관심 메일 분류 → 텔레그램 알림**

- Python으로 메일 조회·분류·알림을 연결하고, GitHub Actions cron으로 주기적으로 실행하도록 만들었습니다.
- Gemini가 메일의 맥락을 보고 기다리던 결과나 관심 있는 내용인지 판단합니다.
- 제 일상의 작은 불편을 직접 만든 도구로 해결한 첫 경험입니다.
- 코드와 실행 방법: **[mail-notifier](https://github.com/Sweet-Butters/mail-notifier)**

### TripPups — 외국인과 로컬을 연결하는 서비스

- 모두의 창업 2기, 8인 팀에서 기술 개발과 사업 모델, 외국인 커뮤니티 관련 업무를 담당했습니다.
- 실제 외국인 대상 로컬 행사를 운영하며 현장의 수요를 확인했습니다.
- 카카오 MCP 심사를 통과했으며, 업체 20곳으로부터 입점 희망 의사를 확인했습니다.
- 서비스: **[trip-pups.com](https://trip-pups.com)**

### 해커온 — AI 해커톤 기획·운영

- 참가자 40명을 선발하는 AI 해커톤을 기획하고 운영했습니다.
- 광고비 없이 공모전 사이트를 통해 행사를 알렸습니다.
- ElevenLabs에 직접 콜드메일을 보내 총 880달러 상당의 40명분 이용권 후원을 유치했습니다.
- Lovable에서 참가자 40명분의 크레딧을 후원받았습니다.
- 행사: **[hackon.kr](https://hackon.kr)**

### 채널감 — 롱폼 AI 영상 편집기

- AI 파이프라인 검증, 사업화와 유통을 맡았습니다.
- 연세 캠퍼스타운 AI 스타트업 해커톤 예선 1위, TOP 10에 선정되었습니다.
- 연세 학생창업경진 왕중왕전 서류 심사를 통과했습니다.

### 난테니스 · AI 콘텐츠

- 서강대학교 동업자와 창업하며 테니스 모임 앱 **난테니스**와 AI 콘텐츠를 제작했습니다.
- 서강대학교 경영학과 교수에게 인턴 기회를 직접 요청하며 실무 경험을 넓혔습니다.
- **연세 프리미엄 AI 인강 5기** 강의를 제작했습니다.

## 일하는 방식

- **먼저 움직입니다.** 필요한 배움과 기회가 있으면 직접 연락하고 실행합니다.
- **현장에서 확인합니다.** 제품을 만드는 과정에 사용자와 파트너의 반응을 연결합니다.
- **끝까지 연결합니다.** 기획과 개발을 실제 운영, 사업화, 유통으로 이어갑니다.
